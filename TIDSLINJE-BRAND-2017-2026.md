|---|---|---|

| **7 nov 2025** | **Erica Güler och Thomas Bartsch, Torsbygatan 10** | Besöker lägenhet 1202. Thomas Bartsch har själv Familjebostäder som hyresvärd och erfarenhet av hur Familjebostäder arbetar som hyresvärd. |

| **11 nov 2025** | **Jennifer Ehlin / Gaby Khalaf / Familjebostäder** | Brandfrågan tas upp vid mötet i lägenheten. Exakta uttalanden om branden ska verifieras mot ljudoriginal/transkription innan de återges ordagrant. |
| **30 nov 2025** | **Erica Güler → Jennifer Ehlin** | Hänvisar skriftligen till branden den 16 november 2017, uppgifter från tre grannar och att händelsen finns noterad på Brottsplatskartan/Polisens händelserapport. Frågar om lägenheten någonsin sanerats efter brandtillbudet. |
| **2 dec 2025** | **Jennifer Ehlin** | Skriver att lägenheten ”självklart” har sanerats efter en eventuell brand, men att hon inte har dokumentation eftersom händelsen ligger nästan nio år tillbaka i tiden. |
| **2 dec 2025** | **Jennifer Ehlin** | Skriver att de boende säkert blivit evakuerade vid brand och att det ”tog säkert tid för oss att sanera lägenheten”, men att fastighetssystemet inte innehåller så gammal information. |
| **10 dec 2025** | **Erica Güler → Jennifer Ehlin** | Påtalar skriftligen att Gaby Khalaf uppgett att ingen brand förekommit, medan Jennifer Ehlin uppgett att lägenheten självklart sanerats efter en eventuell brand. |
| **11 dec 2025** | **Erica Güler → Miljöförvaltningen** | Redovisar att det finns två motstridiga uppgifter från Familjebostäders representanter om huruvida brand inträffat. |
| **7 apr 2026** | **Erica Güler → Stadsbyggnadskontoret** | Frågar om dokumentation efter branden 2017, saneringsintyg och om ventilationen kontrollerats efter branden. |
| **9 aug 2026** | **Erica Güler → Storstockholms brandförsvar** | Begär allmänna handlingar och sakkunnigt klargörande om brandhändelsen den 16 november 2017. |
| **10 aug 2026** | **Erica Güler → S:t Erik Försäkring** | Begär handlingar och uppgifter om försäkring, skadeärende och dokumentation kopplad till brandhändelsen 2017. |
| **11 aug 2026** | **S:t Erik Försäkring** | Bekräftar att Familjebostäder var försäkrat genom S:t Erik den 16 november 2017. Uppger att den aktuella skadan inte anmäldes till S:t Erik och att det därför inte finns något skadeärende eller några gallrade skadehandlingar där. |
| **14 aug 2026** | **Storstockholms brandförsvar** | Brandhändelsen verifieras genom händelserapport 2017010144. Uppgifter lämnas även om räddningsinsatsen och fastighetsägarens ansvar efter avslutad insats. |
| **17 aug 2026** | **Restvärderäddning / Tim Nyqvist** | Uppger att någon rapport för händelsen inte har kunnat lokaliseras hos Restvärderäddning och hänvisar till försäkringsbolag som möjlig dokumentationsägare. |
| **24 aug 2026** | **Stadsbyggnadskontoret / Sheida Rowshani** | Uppger att dokument om eventuella kontroller efter en brand inte finns registrerade hos Stadsbyggnadskontoret och inte är handlingar som kontoret vanligtvis kräver efter en brand. |
