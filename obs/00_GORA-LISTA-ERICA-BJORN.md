# 🧭 FAST ARBETSREGEL

Varje ny uppgift ska kunna placeras i:

**DATUM → VAD HÄNDE/SADES → KÄLLA → VAD VISSTE AKTÖREN → VAD GJORDES → VAD SAKNAS → MOTSÄGELSE/OKLARHET → JURIDISK BETYDELSE**

Och klassificeras som:

1. verifierat faktum,
2. partsuppgift,
3. aktörens/myndighetens bedömning,
4. vår analys.

Om den inte går att placera korrekt ska den ligga kvar som kontrollpunkt – inte smygas in som fastslaget faktum.
