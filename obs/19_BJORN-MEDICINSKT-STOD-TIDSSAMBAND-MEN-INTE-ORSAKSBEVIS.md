# 🚨 BJÖRN – MEDICINSKT STÖD: TIDSSAMBAND ÄR RELEVANT, MEN SYMTOM BEVISAR INTE ORSAKEN

Senast uppdaterad: 2026-08-19

## Det viktiga
Internetmedicin beskriver bland annat luftvägsirritation, huvudvärk, trötthet och koncentrationssvårigheter som symtom som kan förekomma i samband med inomhusmiljöproblem och anger att **tidssambandet mellan vistelse i viss miljö och symtom ska efterfrågas**.

Samtidigt anges att det inte finns någon medicinsk undersökning eller provtagning som specifikt kan bevisa att besvären orsakas av inomhusmiljön.

## Teorin spricker här
Det går därför inte att avfärda ett återkommande plats-/tidssamband bara med argumentet att Erica inte kan visa ett medicinskt prov som pekar ut ett visst ämne.

Men det omvända gäller också: symtomen bevisar inte mögel, VOC, sot eller någon annan specifik exponering.

### Den korrekta kedjan är
**Rapporterade symtom + tidssamband → medicinskt relevant signal → teknisk miljöutredning behövs för att söka orsaken.**

## Koppling till Miljöförvaltningen
Detta ska användas som stöd i analysen av **utredningens tillräcklighet**, inte som bevis för en viss orsak eller ett automatiskt krav på VOC-prov.

## Huvudfråga
> När flera personer rapporterar återkommande reaktioner med plats-/tidssamband, vilken sakkunnig teknisk utredning genomfördes för att identifiera eller utesluta möjliga orsaker i själva bostaden?
