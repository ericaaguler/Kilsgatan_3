# Inspelningar

Här läggs daterade originalinspelningar.

## Filnamn

`ÅÅÅÅ-MM-DD_KLHHMM_deltagare_plats-eller-amne.ext`

Om exakt tid saknas:

`ÅÅÅÅ-MM-DD_tid-okand_deltagare_amne.ext`

## Regler

- Behåll originalfilen oförändrad.
- Ange inte en gissad tid som säker.
- Registrera inspelningen i bevisregistret.
- Koppla senare inspelningen till en ordagrann transkription.
- Hänvisa till tidskod när ett uttalande förs in i tidslinjen.
