# Kilsgatan 3 – bevis- och korrespondensarkiv

Detta privata repository är en källbaserad kunskapsbank.

## Syfte

Att samla och ordna:

- originalbevis,
- korrespondens med Familjebostäder/förvaltaren,
- korrespondens med Miljöförvaltningen,
- daterade inspelningar,
- ordagranna transkriptioner,
- en kronologisk tidslinje över vad som faktiskt har sagts och gjorts.

## Grundregel

Ingen sakuppgift ska föras in i tidslinjen utan hänvisning till ett uppladdat originalbevis.

Repositoryt ska inte innehålla:

- egna teorier,
- spekulationer,
- juridiska argument,
- analyser från samtal,
- sammanfattningar som förstärker eller förändrar originalets innebörd.
