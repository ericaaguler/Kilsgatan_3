# Medicinskt stödunderlag – Kilsgatan 3

Detta spår innehåller medicinska källor som kan användas för att förstå och strukturera de rapporterade hälsobesvären.

## Viktig metodgräns
Medicinska källor används här för att bedöma:
- om symtombilden är förenlig med inomhusrelaterade besvär,
- om tidssambandet mellan vistelse och symtom är medicinskt relevant,
- vilken typ av medicinsk respektive miljöteknisk utredning som normalt behövs.

De används **inte** som bevis för att en viss byggnadsskada, mögel, VOC, sot eller annan specifik exponering finns i Kilsgatan 3.

## Aktuell huvudkälla
### Internetmedicin – Fukt- och mögelrelaterade hälsobesvär
Se:
`2026-08-19_INTERNETMEDICIN-INOMHUSRELATERADE-HALSOBESVAR.md`

Källan beskriver bland annat:
- luftvägsirritation,
- huvudvärk,
- trötthet,
- koncentrationssvårigheter,
- astmaförsämring,
- dålig/obehaglig lukt,
- betydelsen av tidssamband mellan vistelse i viss miljö och symtom.

Den anger också att det inte finns någon medicinsk provtagning som ensam kan visa att symtom orsakas av inomhusmiljön. Det gör miljö-/byggnadsutredningen till ett separat och centralt spår.

## Koppling till huvudärendet
Det medicinska spåret ska kopplas till:
- Beviskedja A – hälsobesvär,
- Beviskedja B – utredningen av orsaken,
- Miljöförvaltningens utredningsansvar,
- frågan om vilka möjliga miljöorsaker som faktiskt identifierats eller uteslutits.

## Säker huvudformulering
> Den rapporterade symtombilden och det återkommande tidssambandet med vistelse i bostaden är medicinskt relevanta att utreda, men de identifierar inte i sig orsaken. Därför måste medicinsk bedömning hållas isär från den tekniska orsaksutredningen av inomhusmiljön.
