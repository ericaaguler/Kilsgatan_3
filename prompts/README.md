# PROMPTS – KILSGATAN 3

Detta lager innehåller styrande arbetsinstruktioner för AI-stödd juridisk analys i projektet.

## Styrande masterprompt

`PROMPT-AI-JURIDISK-KONTROLL-KVALITETSSAKRING-OVERKLAGANDE.md`

Används som övergripande kvalitets- och kontrollmodell för juridisk research, dokumentgranskning, source-lock, motpartsgranskning, processanalys och arbete med MÖD-överklagandet.

Prompten är **arbetsmetod, inte rättskälla**. Juridiska slutsatser måste fortfarande verifieras mot aktuell primär rättskälla och faktiska originalhandlingar.

Kärnprincip:

`KÄLLA → RÄTTSREGEL → REKVISIT → VERIFIERAT FAKTUM → TILLÄMPNING → SLUTSATS → MOTARGUMENT → KONTROLL`

## Förhållande till övrig struktur

Promptlagret styr hur material i följande delar ska analyseras:

- `STORA-AUDITEN/`
- `juridik/`
- `bevis/`
- `anteckningar/`
- `TIDSLINJE.md`

Vid konflikt mellan en äldre AI-sammanställning och verifierad originalkälla gäller alltid originalkällan.
