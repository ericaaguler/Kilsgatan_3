# PROMPTS – KILSGATAN 3

Detta lager innehåller styrande arbetsinstruktioner för AI-stödd juridisk analys i projektet.

## 1. Styrande masterprompt – juridisk kontroll

`PROMPT-AI-JURIDISK-KONTROLL-KVALITETSSAKRING-OVERKLAGANDE.md`

Används som övergripande kvalitets- och kontrollmodell för juridisk research, dokumentgranskning, source-lock, motpartsgranskning, processanalys och arbete med MÖD-överklagandet.

## 2. Försvarbar juridik och spårbarhet

`PROMPT-FORSVARBAR-JURIDIK-SPARBARHET-OCH-OVERPRÖVNING.md`

Används när ett argument, beslut eller överklagande ska testas för om resonemanget verkligen går att rekonstruera, verifiera och försvara vid kritisk granskning. Prompten fokuserar särskilt på:

- auktoritativa källor,
- juridisk kontext,
- spårbar resonemangskedja,
- vad som inte sägs eller saknas i underlaget,
- starkaste rimliga motargument,
- överprövning och PT-relevans,
- minskad verifieringsbörda,
- försvarbarhet inför myndighet eller domstol.

Kärnfråga:

`KAN JAG VISA KÄLLAN → REGELN → TILLÄMPNINGEN → OCH FÖRSVARA SLUTSATSEN NÄR DEN IFRÅGASÄTTS?`

## Gemensam status

Prompterna är **arbetsmetod, inte rättskälla**. Juridiska slutsatser måste alltid verifieras mot aktuell primär rättskälla och faktiska originalhandlingar.

Gemensam kärnprincip:

`KÄLLA → RÄTTSREGEL → REKVISIT → VERIFIERAT FAKTUM → TILLÄMPNING → SLUTSATS → MOTARGUMENT → KONTROLL`
