# 2. Akt 1–107 – kontrollram

Den numrerade akten ska inte längre behandlas som en klump. Varje aktpost ska få minst följande metadata:

`aktnummer → datum/tid → dokumenttyp → avsändare → mottagare → konkret sakfråga → nytt faktainnehåll → vad myndigheten gör med uppgiften → om parten får den → om parten svarar → om uppgiften återkommer i beslutet → originalstatus`

## 2.1 Kritisk kedja som ska låsas först

**Akt 84 → Akt 89 → Akt 90 → Akt 91–92 → Akt 93 → Akt 94 → Akt 95 → Akt 96–104 → Akt 105 → Akt 106 → Akt 107**

För varje konkret fråga ska kontrollen vara:

`fråga → vem ställde den → vem skulle svara → svarstid → faktiskt svar → verifiering → kommunicering till Erica → Ericas möjlighet att bemöta → uttrycklig bedömning → beslutsskäl`

### Frågor som ska följas genom hela kedjan

1. Sanering efter branden 2017.
2. Om/när kanalrensning utförts.
3. Tidigare kanalrensning och uppgiften om nekad åtkomst.
4. Exakt primärkälla för senare uppgift om `5 m upp`.
5. VOC/toxin/rökpartikel-frågan – **vad undersöktes faktiskt?**
6. OVK-system/räckvidd för objekt 60020562/0562.
7. Köket `saknar don` – vad betyder detta tekniskt och hur bedömdes det?
8. 23 dygns genomvädring.
9. Vittnesuppgifter och deras juridiska/faktiska funktion.
10. Stinas egna observationer och var de dokumenterades.
11. Vilka handlingar Erica fick möjlighet att bemöta före beslutet.
