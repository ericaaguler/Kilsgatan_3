# FRÅGOR – Kilsgatan 3

Den här mappen är det gemensamma **frågeregistret för Erica + Björn**.

Syftet är att varje fråga som uppstår under bevisgenomgången ska få:

- en exakt formulering,
- en tydlig mottagare,
- ett skäl till varför frågan behövs,
- koppling till relevant beviskedja,
- status.

## Statuskoder

- 🔴 **ÖPPEN – HÖG PRIORITET**
- 🟠 **ÖPPEN – VIKTIG**
- 🟡 **KONTROLLFRÅGA / BEHÖVER ORIGINAL**
- 🟢 **BESVARAD**
- ⚪ **RESPONDED – QUESTION NOT ANSWERED**
- ⚫ **UNANSWERED**

## Arbetsregel

Frågorna ska vara korta och neutrala. Vi ska inte lägga in hela teorin i frågan och inte anklaga mottagaren. Ett svar, ett uteblivet svar eller ett sidospår kan därefter registreras som nytt bevis.
