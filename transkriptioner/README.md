# Transkriptioner

Transkriptioner ska kopplas till motsvarande originalinspelning.

## Filnamn

Använd samma grundnamn som inspelningen och ändelsen `.md` eller `.txt`.

## Transkriptionsregler

- Skriv ordagrant.
- Identifiera talare när det går att göra säkert.
- Ange tidskoder löpande.
- Skriv `[ohörbart]` när något inte kan uppfattas.
- Skriv `[osäker transkription: ...]` när ordalydelsen är osäker.
- Rätta inte grammatik och fyll inte i saknade ord.
- Lägg eventuell kort saklig metadata före transkriptionen, men ingen analys.

## Mall

```text
Originalinspelning:
Datum:
Tid:
Plats/ärende:
Deltagare:
Bevis-ID:

[00:00:00] TALARE:
[00:00:00] TALARE:
```
