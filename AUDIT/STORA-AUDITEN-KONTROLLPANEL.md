# 0. STATUSNYCKEL

**Tidslinje/status**
- `INNE` = ska finnas i huvudtidslinjen
- `LÅS` = original-/datum-/citatkontroll återstår
- `SPÅR` = hör till angivet huvudspår
- `NY` = nyligen identifierad och ännu inte fullt integrerad
- `EJ EXTERN` = får inte användas externt som verifierat faktum ännu

**Originalstatus**
- 🟢 LÅST ORIGINAL
- 🟡 ORIGINAL FINNS MEN EXAKT POST/CITAT MÅSTE LÅSAS
- 🟠 ENDAST SEKUNDÄR ÅTERGIVNING / SKÄRMBILD / SAMMANSTÄLLNING
- 🔴 TRANSKRIPTION EJ LJUDVERIFIERAD
- ⚪ TEORI / EJ VERIFIERAD
