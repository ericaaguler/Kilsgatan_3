# Bostadsförmedlingen – Kilsgatan 3

Status: eget bevis-/kunskapsspår. Ska hållas skilt från Miljöförvaltningen, Stadsbyggnadskontoret/PBL och Familjebostäders tekniska ansvar.

## Varför detta spår sparas

Detta spår används för att dokumentera:

1. vad Erica fick eller inte fick veta före accepterandet av lägenheten,
2. vilken information som fanns i annons/visning/förmedlingsledet,
3. vilka frågor Erica senare ställde till Bostadsförmedlingen om besiktning, kvalitetssäkring och kända brister,
4. vad Bostadsförmedlingen svarade eller inte svarade,
5. om det finns uppgifter som kan vara relevanta för frågan om informationskedjan före inflyttning.

Detta spår ska **inte** automatiskt behandlas som bevis för att Bostadsförmedlingen haft ett juridiskt ansvar för lägenhetens tekniska skick. Den rättsliga betydelsen måste verifieras separat innan argument förs.

## Identifierat dokument

### 13 januari 2026 – mejl till Bostadsförmedlingen

Erica skrev till Bostadsförmedlingen med anledning av en annan Familjebostäder-lägenhet på Kilsgatan 15 och hänvisade till erfarenheten från Kilsgatan 3.

I mejlet frågade Erica bland annat:

- hur Bostadsförmedlingen säkerställer att förmedlade lägenheter är beboeliga vid inflyttning,
- vilken kontroll/kvalitetssäkring som görs av hyresvärdens uppgifter,
- om besiktningsprotokoll finns och kan lämnas ut,
- om Bostadsförmedlingen känner till pågående ärenden, klagomål eller tillsyn,
- varför besiktningsprotokoll inte bifogas annonser.

Källa i uppladdad batch: `mail till bostadsförmedlingen stockholmstad (1).pdf`.

### Viktig bevisklassificering

Detta dokument visar med säkerhet **vad Erica uppgav och vilka frågor hon ställde**. Det visar inte i sig:

- att Bostadsförmedlingen kände till branden 2017 före förmedlingen,

# Viktig sakfråga för Kilsgatan 3

Erica uppger att hon inte skulle ha tackat ja till lägenheten om hon före accepterandet hade känt till att en tidigare brand-/rökhändelse inträffat och att verifierbar dokumentation av efterföljande sanering inte kunnat visas.

Detta är relevant som **partsuppgift om beslutssituationen före kontraktet** och som underlag för att undersöka vilken information som faktiskt fanns tillgänglig i förmedlingskedjan.

Det ska ännu inte formuleras som att någon aktör rättsligt var skyldig att lämna just denna uppgift utan rättskällekontroll.

# Relevans för huvudärendet

Bostadsförmedlingsspåret är i första hand ett **informations- och kunskapsspår**.

Möjlig betydelse:

- visar vilken information Erica hade när hon tackade ja,
- kan belysa om uppgifter om tidigare brand/skada/renovering överhuvudtaget fanns i förmedlingsmaterialet,
