# Stadsbyggnadskontoret – OVK objekt 60020562/0562, system 01

## Syfte
Separat mapp för korrespondens och handlingar som rör Stadsbyggnadskontorets hantering av OVK-frågan för Kilsgatan 3, objekt 60020562/0562, särskilt system 01, samt frågan om dokumentation efter branden 2017.

## Viktig dokumentationspunkt 24–25 augusti 2026
Erica frågade uttryckligen den 24 augusti 2026 om det bland Stadsbyggnadskontorets registrerade handlingar finns någon handling där **objekt 0562/system 01** förekommer och begärde ett ja/nej-svar.

I Sheida Rowshanis efterföljande svar anges i stället **"objekt 0561/system 01"** och hon frågar om detta är Ericas lägenhet samt var uppgiften skulle förekomma. Detta trots att den föregående mejltråden uttryckligen anger **Kilsgatan 3, objekt 60020562/0562**, och att frågan gäller OVK-protokoll/ombesiktning.

Detta ska dokumenteras som en handläggnings-/kommunikationsobservation: svaret tyder på att den konkreta objektsangivelsen och den redan lämnade förklaringen inte har följts genom mejltråden. Det ska inte i sig beskrivas som ett bevis för lagbrott, men är relevant vid bedömning av om de konkreta frågorna faktiskt har besvarats.

## Kända uppgifter som ska hållas ihop i denna mapp
- Kilsgatan 3, lägenhet 1202.
- Objekt: **60020562 / 0562**.
- Fastighetsägare: AB Familjebostäder, org.nr 556035-0067.
- Frågan gäller vilket OVK-underlag som omfattar ventilationssystemet för Kilsgatan 3 och om separat handling/ombesiktning finns för system 01.
- Ombesiktningshandlingen 8 november 2022 som hittills identifierats gäller system 02 och bostäder 7–11 samt anger att samtliga ventilationssystem inte ingår.
- Stadsbyggnadskontoret har uppgett att OVK-ärende 2022-20313 avslutades efter godkänt resultat vid ombesiktning.
- Stadsbyggnadskontoret har samtidigt uppgett att kontroller efter brand inte är dokument som de har registrerade hos sig och inte något de vanligtvis kräver efter brand.

## Dokument som ska läggas här
- Komplett mejltråd 20–25 augusti 2026.
- OVK-protokoll april 2022.
- Ombesiktning 8 november 2022.
- Eventuellt separat protokoll för system 01.
- Handlingar från tillsynsärende 2026-06369 som visar att objekt 60020562/0562 redan identifierats för Stadsbyggnadskontoret.
- Eventuella senare svar från Jenny Hamrin, Sheida Rowshani eller annan handläggare.

## Kontrollfråga som fortfarande är obesvarad
**Finns det bland Stadsbyggnadskontorets registrerade handlingar någon handling där objekt 60020562/0562 och/eller system 01 för Kilsgatan 3 kan följas? Om ja: vilken handling? Om nej: bekräfta att sådan handling saknas.**
