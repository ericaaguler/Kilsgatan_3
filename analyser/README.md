## Arbetsregel

Analys ska alltid skilja mellan:

1. **direkt styrkt av original**,  
2. **partsuppgift/vittnesuppgift**,  
3. **slutsats/indicie**,  
4. **hypotes som kräver verifiering**.

Domstolsstrategin ska fokusera på verifierbara motsägelser, spårbarhetsluckor och utredningsbehov – inte på att överdriva vad en bild, luktuppgift eller enskild mätning ensam bevisar.
